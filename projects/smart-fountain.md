# Smart Pet Water Fountain Prototype — Phase I

Phase I of the Smart Pet Water Fountain Prototype focuses on foundational product design, infrastructure planning, and security testing. This stage establishes the technical groundwork for a future commercial smart pet fountain, including 3D modeling, secure web hosting preparation, and network architecture.

This project demonstrates my ability to combine hardware design, cybersecurity practices, system administration, and network engineering into a cohesive prototype environment.

---

## Project Overview

Phase I delivers a complete proof‑of‑concept for the Smart Pet Water Fountain, including:

- Full 3D hardware renderings created in Autodesk Fusion  
- A hardened backend web server prepared for future product integration  
- Local hosting infrastructure using OPNSense, Ubuntu Server, and TurnKey Linux  
- Security testing using Kali Linux and OpenVAS  
- A self‑contained router + firewall + server environment for future deployment  

This phase validates the technical feasibility of the product and prepares the foundation for Phase II (embedded electronics, sensors, automation logic, and IoT integration).

## Technical Challenges & Solutions

### **1. 3D Model Creation & Printing**
Creating a functional prototype required multiple iterations in Autodesk Fusion and Bambu Studio to ensure printability, structural integrity, and component fit.

### **2. Secure Self‑Hosted Infrastructure**
Building a local hosting environment required configuring OPNSense, firewall rules, VLANs, and hardened Ubuntu/TurnKey Linux servers.

### **3. Web Server Hardening**
Kali Linux and OpenVAS scans identified vulnerabilities that were mitigated through configuration changes, patching, and service hardening.
