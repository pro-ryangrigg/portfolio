Smart Pet Water Fountain Prototype — Phase I

3D Modeling • Secure Infrastructure • Server Hardening • Network Architecture

Project Overview

Phase I of the Smart Pet Water Fountain Prototype focuses on foundational product design, infrastructure planning, and security testing. This stage establishes the technical groundwork for a future commercial smart pet fountain, including 3D modeling, secure web hosting preparation, and network architecture.

This project demonstrates my ability to combine hardware design, cybersecurity practices, system administration, and network engineering into a cohesive prototype environment.

Key Features of Phase I

  • Proof‑of‑concept water fountain design
  • Complete Fusion rendering of the first‑generation prototype
  • Local self‑hosted infrastructure for future IoT dashboard
  • Security‑tested backend environment
  • Firewall‑protected network with isolated segments

Technical Challenges & Solutions

  • 3D Model Creation & Printing: Multiple iterations to ensure structural integrity and printability.
  • Secure Self‑Hosted Infrastructure: Required careful firewall configuration, VLANs, and hardened servers.
  • Web Server Hardening: Vulnerabilities identified through OpenVAS were mitigated through patching and configuration changes.

Results & Impact

Phase I produced a fully working prototype, complete 3D renderings, and a secure backend environment ready for Phase II integration. The project was demonstrated locally at Lake Superior College and validated the technical feasibility of the product.

What I Learned

  • Advanced 3D modeling in Autodesk Fusion
  • 3D printing workflows using Bambu Studio
  • Firewall configuration and network segmentation with OPNSense
  • Vulnerability scanning and remediation using OpenVAS
  • Server deployment using TurnKey Linux
  • Secure backend design for future IoT applications
