Remote Imaging Server

Enterprise Imaging • Automation • Windows Server • USAF Infrastructure

Project Overview

The Remote Imaging Server modernized and expanded the imaging capabilities of the 148th Air National Guard, enabling administrators to reimage computers anywhere on the network using a standardized USAF Windows image. After imaging, systems automatically join the domain with no manual intervention.

This project replaced an outdated Windows Server 2012 system that only supported local imaging and required manual domain‑joining. The new solution supports full network‑wide deployment, automation, and standardized workstation provisioning.

My Role

  • Procured and deployed replacement server hardware
  • Installed and configured Windows Server 2019
  • Built and configured the remote imaging environment
  • Automated domain‑joining using a secure service account
  • Created a comprehensive imaging guide for USAF bases worldwide

Tools & Technologies

  • Windows Server 2019 — OS installation, imaging services, automation
  • Server Hardware — procurement, configuration, deployment
  • Custom USAF Windows Image — standardized workstation deployment
  • Snipping Tool / PowerPoint — documentation and visual guide creation

Key Features

  • Remote imaging across the entire network
  • Automatic domain‑joining after imaging
  • Standardized USAF Windows image deployment
  • Clear, step‑by‑step imaging guide for other bases

Technical Challenges & Solutions

  • Local‑only imaging limitations: Upgraded to full network‑wide imaging capabilities.
  • Manual domain‑joining: Automated using a secure service account.
  • Lack of documentation: Authored a complete Remote Imaging Guide used across the USAF.

Results & Impact

The new Remote Imaging Server was adopted by dozens of USAF bases worldwide, helping to image tens of thousands of computers. It significantly reduced man‑hours by eliminating manual domain‑joining and enabled imaging in sensitive or restricted areas without requiring IT staff to be physically present.

What I Learned

  • Windows Server 2019 imaging configuration
  • Automating domain‑joining with service accounts
  • Writing scalable documentation for large organizations
  • Designing infrastructure for distributed, secure environments
